Preferred places input

Started 2026-11-23 10:32 UTC · Page: profile edit, field „Preferované mestá alebo obce“ · Status: chosen — A4, implemented in PR #102

Prompt

let's explore (create a simple static html css js (stimulus) pages that matches the look & feel for from the page) possibilities how to improve the Preferované mestá alebo obce input.

problems.
- it is hard to locate what is already selected
- if I have multiple options the text says 'a dalsie'. so I have to save an go to the profile page to see what am I following.

ideas
- someting like a tags input with the ability to remove each of the selected municipality by clicking on a close button next to it.
- multiple rows to surface the text.

Problems

  • It is hard to see what is already selected: the selection lives only in the placeholder.
  • With more than two places the placeholder ends with „a ďalšie“, so the full selection is visible only on the profile page after saving.

Ideas

  • User: a tags input, each selected place removable with its own × button. → A, B
  • User: multiple rows to surface the text. → D
  • Suggested: selected places as a list of rows under the search field. → C
  • Suggested (round 5): reuse the active-filter pills from the issues filter page. → A2–A4

Options

All options run on the portal's real CSS and the same checkboxes (user[municipality_ids][], user[municipality_district_ids][]). „Uložiť“ shows what the form would submit.

  1. 0 · DnesProduction behaviour as a baseline: the selection only in the placeholder, „a ďalšie“ after two places.
  2. A · Štítky nad poľomSelected places as tags with × above the search field; the field is only for searching. Municipality greyed next to a district.
  3. A2 · Pilulky ako vo filtriA with the active-filter pills from the issues page: light-blue background, one font style, „Obec - Časť“.
  4. A3 · Pilulky, obec sivouA2, but the municipality is greyed (75 % opacity, passes WCAG AA) instead of the „ - “ separator.
  5. A4 · Pilulky, len časť ✓ chosenA2, but a district pill shows only the district; the full name is in the tooltip and for screen readers.
  6. B · Štítky v poliTags and search in one box, like a classic tag input; Backspace removes the last tag. Not chosen.
  7. C · Zoznam pod poľomSelected places as rows under the search field, districts grouped under their municipality. Not chosen.
  8. D · Súhrn a úpravaClosed field shows the full selection as multi-line text; „Upraviť“ opens the search with the selection pinned on top. Not chosen.

Decision

A4, implemented on the profile page in PR #102 (2026-11-23 12:09 UTC).

  • Shortest pills, same look as the active filters on the issues page.
  • Known trade-off: district names repeat across cities (Staré Mesto in Bratislava and Košice), so two pills can look identical. Claude recommended A3 for that reason; A4 was chosen anyway.
  • Later changes in the PR, outside this exploration: selecting a municipality ticks all its districts, unticking one gives a partial „-“ state, and the same rules in the /dopyty filter.
